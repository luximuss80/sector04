# Bunker 21 Prototype (Godot 4, Mobile)

Прототип 3D-игры от первого лица (survival/adventure) под Android: low-poly тестовая
локация, тач-управление с мультитачем, лут, инвентарь, журнал квестов и запертая
дверь бункера.

## Запуск

1. Откройте папку проекта в **Godot 4.3+** (форматы Godot 4.x, config_version=5).
2. Рендер уже настроен: `Project Settings → Rendering → Rendering Method = Mobile`,
   MSAA выключен, тени направленного света отключены, используется только лёгкий
   `Fog` в `Environment` для сокрытия дальности прорисовки.
3. Для проверки на ПК включена эмуляция тача мышью (`input_devices/pointing/emulate_touch_from_mouse`):
   зажмите ЛКМ в левой половине — джойстик, в правой — вращение камеры.
   Также работают WASD / Space / Shift / E.

## Сборка под Android

- Установите Android Build Template (Проект → Установить...) и укажите SDK/NDK.
- Ориентация: `Display → Window → Handheld → Orientation = Sensor Landscape`.
- Растяжение UI: stretch mode `canvas_items`, aspect `expand` — на экранах 20:9 и
  19.5:9 элементы прижаты к краям через анкоры и не «плывут».

## Управление

| Элемент | Действие |
|---|---|
| Левая половина экрана | Плавающий виртуальный джойстик (движение) |
| Правая половина экрана | Свайп — вращение камеры (мультитач: ходьба + камера одновременно) |
| Центральный прицел | При наведении на интерактив появляется крупная кнопка «ВЗЯТЬ/ОТКРЫТЬ» |
| БЕГ (слева над джойстиком) | Спринт, тратит выносливость (переключатель) |
| ПРЫЖОК / ФОНАРЬ (справа внизу) | Прыжок и фонарик |
| ЖУРНАЛ (слева вверху) | Журнал заданий |
| РЮКЗАК (справа вверху) | Инвентарь: тап по предмету → «Использовать» / «Выбросить» |

## Механики MVP

- `CharacterBody3D`: ходьба, спринт со стаминой, прыжок, гравитация.
- Лут: бочки и ящики (`loot_container.tscn`) дают случайные предметы; пикапы
  (`item_pickup.tscn`) — консервы, вода, бинты, металлолом, ключ-карта.
- Квесты (`scripts/game.gd`): «Собрать 3 металлолома», «Найти ключ-карту»,
  «Открыть дверь бункера» (скрытое задание, открывается после находки ключа).
- Дверь бункера (`bunker_door.tscn`): без ключа — отказ, с ключ-картой — панель
  опускается вниз (Tween), коллизия отключается, задание закрывается.

## Структура

```
project.godot            — настройки: Mobile-рендер, тач, растяжение UI
scenes/main.tscn         — мир: ProceduralSkyMaterial, туман, свет, игрок, HUD
scenes/player.tscn       — CharacterBody3D + Camera3D + RayCast3D + фонарик
scenes/hud.tscn          — весь тач-UI (джойстик, свайп-зона, кнопки, панели)
scenes/objects/*.tscn    — контейнер лута, пикап, дверь бункера
scripts/level_builder.gd — сборка локации из CSGBox3D/CSGCylinder3D + StandardMaterial3D
scripts/game.gd          — автозагрузка: инвентарь, статы, квесты, сообщения
```

Все объекты уровня собираются кодом из CSG-примитивов и `StandardMaterial3D` —
внешних платных ассетов нет. Лесная база на севере (домик с трубой, костёр, мост
через реку, бочки с лутом), пустошь на юге (песчаный берег, деревянный пирс,
полуразрушенные панельные многоэтажки, холм с ржавым остовом корабля и дверью
бункера).
